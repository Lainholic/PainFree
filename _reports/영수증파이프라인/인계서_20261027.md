## 1. 환님 확정 방향
1. 핵심 두 축: ① 평소 통증·컨디션 기록(부위, VAS, 기저질환, 걸음 수) ② 영수증을 **찍어서** 자동 인식 → 추론.
2. 화면에 고정 데이터를 박지 않는다. 입력 폼에 숫자를 치게 하지 않는다. 영수증은 사진 → 글자 인식 → 숫자·문자 파싱 → Nemotron 3 Ultra 550B 순서로 처리한다.
3. 예시 영수증은 직접 만들지 않고 실제 공개된 것을 가져온다(직접 그린 이미지는 삭제함).
4. 걸음 수: 직접 입력 + API 연동 둘 다 보여주는 방향. 현재 웹은 직접 입력만 구현.
5. 환자등록번호 불필요(삭제 완료).
6. 결과물은 진단·법률 판정이 아니라 "원무과 확인 질의서 참고 초안".
